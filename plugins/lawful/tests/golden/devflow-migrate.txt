## Law 草稿(四格 → 三行;`<…>` 是人要補的)
### G-F001-ui-loop
- LAW-1 [<種類>] 未知事件是恆等
  - forall w in World
  - |- routeEvent Unknown w == w
### gameplay/E001-fast-scan
- LAW-1 [<種類>] 與慢掃一致
  - forall ms in MapStatic
  - |- scanFast ms == scanSlow ms
### gameplay/F001-collision-query
- LAW-1 [<種類>] 不穿牆  ← 需形式化
  - forall p in Rect, d in Vec2
  - given <起點本身不與任何實心 tile 重疊>
  - |- <resolveMove … 需形式化:`resolveMove` 回傳位移後的 AABB,不與任何實心 tile 重疊>
- LAW-2 [<種類>] 零位移回零
  - forall p in Rect
  - |- resolveMove ms layer [] me p (Vec2 0 0) == Vec2 0 0
### gameplay/F002-text-localize
- LAW-1 [<種類>] 已載入語系嚴格遞增  ← 需形式化
  - forall t in I18nTables
  - |- <localesOf t … 需形式化:`localesOf t` 相鄰兩項嚴格遞增>
- LAW-2 [<種類>] 查不到回醒目標記
  - forall t in I18nTables, l in LocaleId, k in <定義域待補>
  - given not (hasLocale t l)
  - |- localize t l k [] == "!!missing!!"
- LAW-3 [<種類>] 舊寫法 —— 對所有 t,localize 不會 throw
  - <這條不是四格寫法,整條重寫>
