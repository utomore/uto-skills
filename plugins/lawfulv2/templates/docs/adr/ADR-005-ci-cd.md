# ADR-005：CI 與 CD

- 狀態：採用
- 日期：<YYYY-MM-DD>

## 背景

<這個專案現在要自動化到哪裡：只在 PR 上跑檢查，還是連建置與部署都自動；部署到哪裡、誰可以放行。>

## 決策

**CI：**<用什麼跑、什麼時候跑、跑哪幾步；哪幾步綠了才能合進主線。本地檢查（ADR-004）與 CI 跑的是不是同一道。>

**CD：**<要不要自動部署、用什麼、部署到哪些環境、誰放行。現在不做就寫「現在只有 CI」與打算什麼時候再定。>

- <自動化到這裡帶來什麼、還有哪些要人手做。>
