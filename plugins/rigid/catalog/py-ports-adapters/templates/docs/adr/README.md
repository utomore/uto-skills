## 待決定

方向已定、細節還要討論的，定案時各寫成一份 ADR。

- <例：系統資料庫用什麼、migration 怎麼管>

每份包含：狀態（提議、採用、被 ADR-xxx 取代）、日期、背景、決策、後果、否決的做法。
上線之前是第一版的建置期：決策改了就直接改寫那一份，背景只寫這個案子的需求與限制。
上線之後決策改了才寫新的一份，舊的狀態改成「被 ADR-xxx 取代」，不改寫舊的內容。
