# Layout 版型詞彙表(共用)

投影片版面一律由 `talk/src/theme.css` 的版型類別組成,不逐頁手刻 CSS。本表是 section-impl 規劃「這頁怎麼呈現」與 page-adjust「換版面」時的共同語言;review 檢查跨頁版面語彙是否收斂也以此為準。

## 整頁類別(寫在該頁開頭的 `<!-- _class: ... -->` 指令)

| 類別 | 用途 |
|---|---|
| `title` | 封面:大標 + 副標 + 講者,置中 |
| `divider` | 章節隔頁:section 名稱 + 一句話,轉場用 |
| `center` | 內容置中:單一句結論、大數字、單張大圖 |
| (無) | 一般內容頁:標題在上,內容區在下 |

## 內容區版型(標題下方放一個 grid 容器 div)

寫法:容器 div 內每個直接子 `<div>` 是一格,格內寫 Markdown(**div 標籤與內容之間必須留空行**,否則 Markdown 不解析):

```markdown
## 頁面標題

<div class="cols-2">
<div>

- 左欄條列

</div>
<div>

![h:400](../assets/diagram-02-1-arch.svg)

</div>
</div>
```

| 類別 | 格局 | 適用 |
|---|---|---|
| (不放容器) | 整頁單一區塊 | 一段論述、一份條列、一張表 — 內容本身就是一個整體時**不要硬切格** |
| `cols-2` | 左右對分 | 對比、文+圖 |
| `cols-2-1` | 左寬右窄(2:1) | 主內容+側註/小圖 |
| `cols-1-2` | 左窄右寬(1:2) | 條列導讀+大圖 |
| `cols-3` | 直分三等份 | 三個並列概念 |
| `rows-2` | 上下對分 | 前因後果、上圖下表 |
| `rows-3` | 上中下三段 | 有先後或層次的三段內容(現況→問題→解法) |
| `grid-2x2` | 四等份(2×2) | 四象限、四個要素 |
| `grid-3x2` | 上三下三(3 欄 2 列) | 六個並列小項 |
| `grid-2x3` | 左三右三(2 欄 3 列) | 兩組各三項的對照 |
| `rows-3-2` | 上三下二 | 五個項目(上 3 下 2 置中) |

- 格數 = 子 div 數;缺格會塌陷,先數好再寫
- 格內可加 `class="card"` 畫出邊框卡片 — **只在需要視覺分組時用**,整份簡報每頁都三張等寬卡片是 AI 感的頭號來源,review 會扣分
- 巢狀勿超過一層(grid 裡再放 grid 即是資訊超載,拆頁)

## 內文形式與擺放

- **條列**:一層為主,每點一行內講完;超過 5 點改用 grid 分組或拆頁
- **表格**:只在「多列 × 多維度」對比時用;3 欄以內、5 列以內,超過就是查閱資料不是投影片
- **段落文字**:一頁最多一小段(3 行內),用於定義、引言、結論句
- **圖形**:嵌入哪一格由本頁重點決定 — 圖是主角就給大格(`cols-1-2` 的右格、`rows-2` 的上格)或整頁 `center`;圖是輔助就放窄格
- **截圖加註頁**的慣用格局:加註圖佔大格(`rows-2` 上格或近整頁),下方以並列格放編號圖例(3 個標記 → `cols-3`,每格「編號 + 短標 + 一行說明」);圖例編號順序 = 標記在圖上的動線順序
- 圖片尺寸用 Marp 語法控制:`![h:400](...)` 限高、`![w:560](...)` 限寬;圖在格內置中由 theme 處理

## 選版型的判斷順序

1. 這頁的一句話重點是什麼?(說不出來 → 回 section 設計文件)
2. **內容是一個整體還是多個並列?** 一個整體(單一論述、單份條列、單張表、單張圖)→ **整頁單一區塊**(無容器或 `center`),切格反而打斷閱讀;有先後層次 → `rows-2` / `rows-3` 上下切分。**「切成多格」只是選項之一,不是預設** — 沒有並列或對比關係就不要切
3. 重點是**圖**還是**文**?圖為主 → `center` / `cols-1-2`;文為主無圖 → 無類別或 grid;對比 → `cols-2` / `grid-2x3`
4. 並列項目幾個?2 → `cols-2`,3 → `cols-3`,4 → `grid-2x2`,5 → `rows-3-2`,6 → `grid-3x2`,更多 → 拆頁
5. **走一遍視覺動線**:選定版型後自問聽眾的眼睛從哪進、依什麼順序看、在哪停 — 動線該與內容的邏輯順序一致(左→右 = 先→後、上→下 = 因→果);說不出動線就換版型或減量
6. 相鄰頁盡量**不要連續換版型語彙**:同一 section 內同類內容用同一版型,聽眾才不用每頁重新找重點位置
