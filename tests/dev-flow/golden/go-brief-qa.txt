# F-001-queue：把一行輸入排進優先權佇列並回報深度

## Brief
把一行輸入變成一個 Job 推進佇列，回報目前深度。
input 是 stdin 的一行，output 是深度。流向：推入 → 取深度。

| 1 | `Push([]Job, Job): []Job` | 推一個 job 進佇列 | `internal/queue/queue.go` | core |
| o | `Peek([]Job): (Job, bool)` | 觀察：優先權最高的那個是誰 | `internal/queue/queue.go` | core |

| ! | `Serve(string): string` | 進入點：接到 stdin 的一行 | `cmd/main.go` | entry |

## Laws
- LAW-1 [invariant] 推一個進去，深度多一
  - forall jobs in Job, j in Job
  - |- Depth(Push(jobs, j)) == Depth(jobs) + 1
- LAW-2 [total] 空佇列取不到東西，但不會炸
  - forall jobs in Job
  - |- total(Peek(jobs))

### internal/queue/queue.go（41 行，全文）
```go
package queue

type Job struct {
	ID       string
	Priority int
}

type Queue struct {
	jobs []Job
}

const (
	Low  = 0
	High = 9
)

func Push(jobs []Job, j Job) []Job {
	return append(jobs, j)
}

func Peek(jobs []Job) (Job, bool) {
	if len(jobs) == 0 {
		return Job{}, false
	}
	best := 0
	for i, j := range jobs {
		if j.Priority > jobs[best].Priority {
			best = i
		}
	}
	return jobs[best], true
}

func Depth(jobs []Job) int {
	return len(jobs)
}

func (q *Queue) Size() int {
	return len(q.jobs)
}
```
