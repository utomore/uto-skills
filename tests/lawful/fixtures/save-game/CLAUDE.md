# save-game

## 名詞
名詞只住這一節:新增或調整任何一個領域名詞的定義,一律改這張表,不寫在別處。需求的一句話、驗收、里程碑那一句與 law 的第一句用到的領域名詞,都在這張表上。

| 名詞 | 定義 | 型別 |
|---|---|---|
| 世界 | 遊戲進行中的全部狀態;存檔只收它可存檔的那一部分,算得回來的快取不算 | `World` |
| 存檔 | 世界可存檔的投影寫成的一份內容;不是世界本身 | `SaveState` |
| 實體 | 世界裡有 id 與位置的一個東西 | `Entity` |
| 解碼錯誤 | 存檔讀不回來時講得出原因的錯誤;不是例外 | `DecodeError` |
