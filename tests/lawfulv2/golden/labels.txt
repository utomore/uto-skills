## --help
用法：node labels.mjs [--repo <OWNER/REPO>] [--delete <標籤>]... [--apply]
  --repo    要設標籤的 repo，預設是目前目錄的 repo
  --delete  刪掉一個標籤表以外的標籤（它會從所有 issue 與 PR 上消失），可以寫多次
  --apply   真的動 GitHub；不加只印計畫
標籤表：
  feature   新增的能力或 API
  bug       修正壞掉的行為
  refactor  不改行為的重構、搬家、改名
  docs      只動文件、ADR、計畫或設計稿
  test      只動測試或驗證
  chore     建置、CI、腳本、依賴、工具設定
  decision  待決題（只用在 issue）
  duplicate 關 issue 時用：重複
  wontfix   關 issue 時用：不處理
  種類:目的     少了它，北極星做不到
  種類:延伸     北極星已經做得到，多一種方式或更方便
  種類:工程保證   可靠性與正確性，出事會壞資料或壞狀態
  種類:效能     做得到，但太慢、太大或太耗資源
  種類:開發工具   服務開發的人
  種類:維護     既有的債
exit 2
